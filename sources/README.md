## 4. 解析方法

章程原文是 PDF，正文密集且有表格。本目录用以下方式转成可检索文本：

```bash
python sources/extract.py
```

脚本使用 `pypdf` 逐页 `extract_text()`，输出同名 `.txt`。注意：

- 表格会被打散为逐行文本，**顺序可能与原文视觉排版不同**
- 个别字符可能丢失（如分数中的特殊符号），引用前请回看 PDF 原件
- 页码信息未保留，定位时建议用关键词检索

## 5. 未能核实的事项

诚实记录本文没有验证到的内容：

| 事项 | 原因 |
|------|------|
| 各校《专业大类与可报考高职（专科）专业对应表》原文 | 表在院校招生网单独发布，未随章程 PDF 分发；文中仅引用章程里"须符合对应表"的表述 |
| 2026 年录取分数线的官方版本 | 教育考试院不统一公布，各校公示分散，文中数据来自网络整理 |
| 报录比 | 官方不公布报考人数，任何"报录比"都不可信 |
| 毕业生就业质量数据 | 各校就业质量报告口径不一，暂不引用 |
